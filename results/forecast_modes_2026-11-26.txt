5. GAIN LAW for the tree, split (MiniSHAKE128) over wide (TurboSHAKE128), equal 12 rounds: G = 1/((1-f) + f/g), g = 2 (two Keccak-p[800]
   advance per round clock), f = share of the wide tree's critical-path time spent in permutation rounds.
   Wide atom clocks per hash: leaf 4 absorb + 12 rounds + 8 squeeze + 4 overhead = 28 (f = 0.43); node 8 + 12 + 8 + 4 = 32 (f = 0.375).
   Split moves the same bytes per hash through absorb and squeeze, so only the rounds halve.
   N = 1: f = 0.40 -> G = 1.25 (predicted split/wide speed-up; accept 1.15-1.35). FAILURE if outside 1.10-1.40.
   N = 2: nodes reach the port on both sides, f on the critical path about 0.2 -> G = 1.10 (accept 1.00-1.20).
   N = 4: both sides port bound, f -> 0 -> G = 1.00 (accept 0.95-1.05). FAILURE if G > 1.10 at N = 4.
